The Hydration Reminder App is a React Native mobile application built during Mobile Application Development Lab 6 to demonstrate hardware-level features using Expo APIs. The project utilizes expo-router to implement a multi-tab navigation layout featuring Reminder, Tips, and About screens. It also integrates expo-notifications to schedule, trigger, and cancel repeating local device alerts without relying on external servers. Furthermore, the app securely requests OS-level hardware permissions and utilizes a global foreground handler to ensure alerts display even when the application is actively open.
